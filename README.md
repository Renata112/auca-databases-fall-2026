## Course Overview

This repository contains laboratory assignments completed as part of the Databases course at the American University of Central Asia during the Fall 2026 semester.

The course provides a practical introduction to relational database systems, focusing on database design, SQL programming, data management, transactions, indexing, and backup strategies.

The laboratory assignments progressively develop practical skills in designing, implementing, querying, and managing relational databases using PostgreSQL.

## Technologies and Tools

- **PostgreSQL** — Relational database management system
- **SQL** — Database definition, manipulation, and querying
- **psql** — PostgreSQL command-line interface
- **pgAdmin 4** — Database administration and ER modeling
- **Git & GitHub** — Version control and laboratory submissions

## Learning Objectives

Throughout the course, the laboratory work focuses on developing the ability to:

- Understand relational database concepts and architecture.
- Design ER diagrams and normalized relational database schemas.
- Write basic and advanced SQL queries.
- Implement primary and foreign key constraints.
- Manage database transactions and understand ACID properties.
- Apply indexing and basic query optimization techniques.
- Perform data import, export, backup, and restoration.
- Understand fundamental database administration concepts.

## Repository Organization

Each laboratory assignment is organized in a separate directory. Depending on the assignment, folders may contain:

- SQL queries and scripts
- Screenshots of executed commands and results
- Database schemas and ER diagrams
- Supporting documentation

## Academic Purpose

This repository serves as a collection of practical coursework for the Databases course at AUCA. Its purpose is to document the learning process and demonstrate the application of relational database concepts through hands-on SQL exercises.
